## 世界

**最深的颜色是页面底，白卡浮在它上面。** 这是与上一个世界（「信号室」：暖墨底 +
纸白字 + 琥珀光）最根本的区别 —— 层次靠**色差与留白**建立，不靠描边、不靠发光。
唯一浮起来的东西才配拥有投影：底部动作胶囊、弹层、侧栏品牌块。

## 唯一事实来源

一切颜色/字号/间距/圆角/动效来自 [`client/src/theme-warm.css`](src/theme-warm.css)。
页面与组件 CSS 里**不出现十六进制或 `rgba(...)`**（该文件本身除外）。
官网 `web/` 与管理台仍用 `packages/shared/src/design/tokens.css` 的「信号室」——
两套世界刻意分叉：这次的改造范围只有客户端。

## 与参考稿的三处刻意偏离（都有实测数字）

1. **强调色更深**：参考的 `#9A7F70` 当按钮底压白字只有 3.6:1、当文字压页底 3.1:1，
   两处都过不了 AA。改取同色相更深的 `#6B5245`（白字 7.2:1、压页底 5.4:1），
   浅的那档留作 `--accent-soft`，只用在**非文字**的地方（选中指示底、装饰）。
2. **文字只有三档**：浅底上再排第四档灰，要么与第三档重合、要么过不了 AA。
   所以文字到 `--ink-3` 为止，第四档 `--ink-faint` 明确划给非文字，且仍守住 3:1。
3. **输入框填充单独一档**：直接拿参考的 `--ground-deep`（`#D6CBC2`）当填充，
   占位文字只有 3.9:1；`--field` 是为此单独调出来的一档。

实测脚本：`.cache/check-warm-contrast.mjs`（解析本文件旁的 CSS，含 `color-mix` 求值）
—— 亮色 40 项 + 深色 40 项全部达标，数字见 `theme-warm.css` 里的行内注释。

## 结构（不可随手改的部分）

- 窗口 **940×580**（min 780×520）：这套骨架在窄竖窗里会把链路牌挤成两行。
- 左 **76px** 图标栏：品牌块 56×56 → 四个去处（联机/大厅/收藏/设置，图标 22px、
  标签 12.5px、选中是浅底 + 强调色）→ 底部头像 40px。
- 右侧一列：标题条（页面名 + 状态点 + 窗口按钮，52px）→ 页面（自己滚动）→
  底部一行（左：`McLink v… · Windows 11 Pro · Build …`；右：动作胶囊）。
- **房间不占一栏**：开好房就把房间内容铺在「联机」这一屏里；退房回到开房前那一屏。
- 动作胶囊：`#deck-actions` 是一个白色胶囊容器，由页面用 `Teleport` 送入 ——
  于是"这一屏的主动作"永远在右下角同一个位置（参照稿的签名动作）。

## 刻意不用的写法

- 深色横带式标题栏、卡片描边分层、零偏移发光、玻璃拟态
- 卡里套卡（三步说明是横排三段 + 发丝线，不是三张小卡）
- 用 emoji / Unicode 字形顶替图标（四个图标都是自绘 SVG，统一 1.6 描边）
- 靠颜色单独传达状态（连接状态同时有文字与圆点）
- 展示层用系统字体当"声音"（标题用已自托管的 Archivo；客户端离线可用，不引 CDN 字体）

## 已知的迁移缝合处

`theme-warm.css` 里有一段**兼容映射**：旧世界的令牌名（`--paper` / `--signal` /
`--rule` / `--link` …）按**角色**指向新世界的值，因此既有页面（房间页、设置页、
聊天、诊断…）不改一行就落到新配色里。这些页面还没有按新世界重排（本次范围：
外壳 + 「联机」首页）。把某一页真正搬过来时，应当同时把它的旧令牌名换成新名，
并把该页从这段映射的受益名单里划掉 —— 否则两套名字会长期并存。
