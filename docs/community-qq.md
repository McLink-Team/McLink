## 群介绍（长版，贴"群介绍"或置顶）

```
【这是什么群】
McLink 的官方交流群。McLink 是一个局域网联机工具：不需要公网 IP、不需要端口映射、也不用装任何组网软件，
建个房间把地址发给朋友，大家在游戏里"直接连接"就能一起玩。
支持《我的世界》等各类局域网联机游戏（泰拉瑞亚、星露谷、饥荒、英灵神殿……）。

【为什么不用折腾网络】
它把"组网"这件事藏在了后面：一台主控 + 若干中继节点 + 一个客户端。
玩家侧零配置——网络身份、虚拟地址、中继、启动参数全部由主控下发。
技术上基于 EasyTier，一台主控一个端口就能承载所有房间，房间之间彼此隔离。

【在群里能得到什么】
· 下载最新版客户端（以群公告里的官网链接为准）
· 联机遇到问题时有人帮你看（附界面提示文字或日志，定位快得多）
· 更新公告：每次发版我们会在群里说明改了什么
· 提建议、报 bug —— 你说的问题基本都会进待办

【怎么开始（三步）】
1. 在游戏里"对局域网开放"（Minecraft 在"多人游戏"那一屏）
2. 打开 McLink 创建房间，把房间页上的联机地址复制出来
3. 朋友在游戏里"多人游戏 → 直接连接"，粘贴地址即可

注意：**不少游戏要连端口**，写法是 地址:端口。端口去哪儿看、每个游戏怎么填，客户端里的
「联机帮助」都写清楚了（Minecraft 的端口在"对局域网开放"那一屏，泰拉瑞亚默认 7777）。

【群规（就四条）】
1. 提问带上三样东西：McLink 版本号、Windows 版本、界面上的提示文字（或日志）。
   只说"连不上"我们只能猜，有这三样通常能直接定位。
2. 安装包一律用官方链接，不要转发来路不明的安装包——我们不做任何内测包外传。
3. 不要发别人的房间加入码、密钥、虚拟 IP（那等于把别人的房间钥匙贴出来）。
4. 广告、外挂、破解一律请出。

【一句实话】
用组网工具玩**带反作弊**的游戏是有风险的：有些反作弊会把虚拟网卡或网络驱动视为可疑环境。
McLink 不做任何规避反作弊的功能，也不会为此改系统行为——要不要在某个游戏里用，请你自己判断。

【官方入口】
官网与下载：https://cnnic.link/download
```

## 使用建议

- **群公告固定置顶**，链接只用官网那一个；换版本时只改置顶，不要在群里反复发文件。
- 发版时按 `docs/releases/<版本>.md` 里的"群公告"那段发（已经把技术细节压掉了，
  只留玩家关心的：界面变化、新功能、修了什么）。
- 有人报"卡/丢包"时，让他在房间页展开「连接诊断」和「连接路径」截图 ——
  那里现在会显示是直连还是经中继、延迟与丢包，比问"你是不是网不好"有效。
