# 公告：公共服务端调整（转社区共建）—— 邮件版

> 用途：控制台 →「邮件公告」页的「主题」+「正文」，**纯文本**；也可以勾「按 HTML 发送」用下面的 HTML 版。
> 平台会在正文尾部**自动追加**站点名、站点地址与退订链接，所以正文里**不要**再写签名和退订说明。
> 限制：主题 ≤ 80 字、正文 ≤ 4000 字。收件人是"已验证邮箱且未退订"的用户。
>
> ⚠️ 正文里有一处方括号【公共服务端停止的时间：…】是**需要你确认**的信息：
> 定下来就把括号和提示换成具体日期；不确定就把整句删掉 —— 宁可不说，也别让玩家以为明天就断。
> 另外这条公告没有提"主控 / 下载页 / 账号"的去留，如果那边也要变，建议单独一段写清楚（别让玩家猜）。

## 主题（32 字）

```text
【重要】McLink 公共服务端调整：10 月 7 日起停止官方中继
```

## 正文（纯文本版）

```text
各位好，

在这里跟大家同步一个重要的项目调整。

【变更】
受限于国内网络合规相关要求，后续我将不再提供任何官方中继、公益转发服务器。
个人继续运营公共中继服务，即便作为公益免费服务，也会面临不可忽视的合规风险。

时间点是 10 月 7 日（2026-10-07）：从那天起，主控落地页不再对外提供服务，
也不再接受公开注册（改为邀请制，老账号不受影响）。已经建好的房间在那之前照常可用。

【为什么】
我做这个项目的初衷，仅仅是希望给玩家提供一个简单好用的局域网联机工具。
前期更多聚焦在功能实现，没有充分考虑到深层次的运营合规问题。
经过慎重权衡，决定不再由我个人维护运营公共服务端。

【接下来】
我的重心会放在软件本体的功能维护与 bug 修复上，项目代码会完整开源，转为社区驱动的公益模式。
软件内会保留节点接入入口，大家可以自行接入社区共建的第三方节点（也可以自建，用仓库里的部署脚本）。

【对大家的影响，以及可以怎么做】
1. 联机方式不变：软件本身、房间、聊天、票据这些功能都照常维护，只是"谁来当中继"这件事
   从"平台提供"变成"你自己或社区提供"。
2. 想继续用：在软件里接入社区共建的节点，或者用仓库里的脚本自建一台（一台普通的云服务器就够，
   带宽按你的实际需求买）。接入方式会写在文档和群公告里。
3. 局域网内的直连（同一路由器下、或 P2P 打洞成功）本来就不经过中继，这部分不受影响。
4. 如果你愿意贡献一台节点加入社区共建，欢迎在群里说一声，我会把接入方式整理出来。

感谢一路以来的支持与反馈。这个项目会继续以开源、公益的方式走下去 ——
软件有问题、有想加的功能，照旧在群里说，或者在客户端「设置 → 反馈」里告诉我们。
```

## 发信前检查

1. **先给自己发一封**（控制台「平台设置 → 邮件服务」里有 SMTP 测试），确认能收到、排版正常；
2. **落地页与开关**：控制台「平台设置」里把「注册模式」改成<b>仅邀请码</b>、
   关掉「本实例对公众开放」、填上「停止对外服务的日期」<span class="mono">2026-10-07</span>
   —— 落地页会自动换成"已停止对外服务"那一版（仓库地址、自建步骤、邀请码注册入口都在上面）；
3. **收件人**：群发页会显示"可发送 / 未验证 / 已退订"的人数，先看一眼再点发送（发了不可撤回）；
4. **同步到其它渠道**：这条公告建议同时在群里置顶、把控制台「平台设置 → 公告」也写上一条
   （它会显示在落地页顶部的公告条里），以及在仓库 README 里写明"官方中继已停止，请自建或使用社区节点"；
5. **HTML 版**：勾「按 HTML 发送」并粘贴上面的 HTML；主控会自动补一份纯文本兜底，
   给不支持 HTML 的客户端。撰写框下面有「预览正文」可以先看渲染效果。
