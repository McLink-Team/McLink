## 正文（纯文本，可直接粘贴）

```
尊敬的 McLink 用户：

您好。

McLink 客户端 1.0.6 已发布，本次为功能性更新，安装包可在官网下载页获取。
现将本次更新内容说明如下。

一、本次更新解决的问题

在此前的版本中，客户端只能显示"是否已直连"与延迟，无法反映链路质量。
实际使用中存在一种常见情况：两个用户之间已成功建立 P2P 直连，延迟读数也正常
（常见为 10~30 毫秒），但丢包率偏高。此时游戏内会出现人物位移回弹、操作延迟等
现象，而界面上没有任何信息可以解释这一现象，用户也难以自行判断原因。

本次更新针对该问题，新增了连接质量诊断与中继回落两项能力。

二、新增功能

1. 连接路径显示丢包率

   房间页的「连接路径」列表、以及「连接诊断」中的每个节点，现在都会显示丢包率。
   该数据由 EasyTier 核心统计（最近 100 次探测的滑动窗口），客户端仅作展示。
   若某项数据尚未测得或当前版本不返回该字段，界面显示"—"，不影响其它信息。

2. 一键「强制走中继」

   当 P2P 直连的丢包率超过 5% 时，房间页会提示：
   「P2P 直连在丢包（最高 X%）。」并提供「强制走中继」按钮。

   点击后，本机将不再尝试 P2P 直连，全部流量改由中继转发。该设置会记录在本机，
   重启客户端后重新进入同一房间时仍然生效；随时可以关闭并切回直连。

   注意事项：
   · 切换时本机的网络核心会重启一次，连接中断约 3 秒；
   · 只影响您自己，房间内其他成员不受影响；
   · 若房主在「房间规则」中已关闭「允许 P2P 直连」，则该按钮为只读状态。

3. （可选）自动中继回落

   在「设置 → 联机质量」中，可以开启「P2P 丢包时自动切到中继」。该选项默认关闭。

   开启后，仅在连续 3 个采样窗口（约 36 秒）内、且所有已测得丢包的直连节点
   丢包率均超过 5% 时才会动作。切换到中继后，客户端还会对比一次实际效果：
   若中继侧同样存在丢包或延迟明显增加，会自动切回直连，并在 30 分钟内不再自动切换。
   为确认直连是否恢复，之后每 15 分钟尝试一次直连，连续失败时逐步延长至 1 小时。

   每次自动切换或重试都会造成约 3 秒的连接中断，因此该功能默认关闭，
   建议仅在确实存在链路质量问题时开启。

三、升级方式

直接下载安装包覆盖安装即可，登录状态与本地设置都会保留，无需先卸载旧版本：

https://cnnic.link/downloads/McLink-Setup-1.0.6-x64.exe

已安装旧版本的用户，客户端内也会出现新版本提示，可直接跳转下载页。

四、反馈渠道

使用过程中如遇到问题，请在官方交流群中反馈，并附上以下信息，以便我们准确定位：
· 客户端版本号（窗口左下角）
· Windows 版本
· 界面上的提示文字（截图即可），或「设置 → 日志」中的相关内容

感谢您的使用与支持。

McLink 团队
2026-09-26

────────────────────────────────────────────
McLink —— 基于 EasyTier 的局域网联机平台，支持《我的世界》等各类局域网联机游戏。
官网与下载：https://cnnic.link/download
```

## 发送建议

- **收件人**：全量。本次是功能更新且客户端会自动提示新版本；对"时好时坏、偶尔卡顿"的用户尤其有用。
- **发送顺序**：先上传安装包 → 再部署主控（V19 迁移）→ 最后发公告。
  顺序反了会出现"邮件已经发出、下载链接 404"。
  本机开发库实测过这一步：**只跑迁移、不放安装包时**，`/meta` 与下载页的地址会退回
  `data/downloads/` 里现存的旧产物（`resolveClientDownloadUrl()` 找不到设置里指定的文件名就改挑现存的，
  见 `server/src/api/public.ts`）。放上 1.0.6 的包之后才变成 `/downloads/McLink-Setup-1.0.6-x64.exe`。
  顺带一句：`/meta` 的这个字段是**扫描目录后算出来的**，刚拷完文件的那一两秒里可能还回报上一次的结果，
  核对时以 `/downloads` 为准（它每次按文件现算 sha256）。
- **安装包指纹**（**以本次构建产物为准**）：
  - 文件名 `McLink-Setup-1.0.6-x64.exe`
  - 大小 `91,955,766` 字节
  - sha256 `e8f3f5c5c2f2586487dd9790ac481fa529f46ed8bc5b394a7a4642393635ec60`
  - 主控页面上显示的校验值由它自己按文件计算（`/downloads` 的 sha256 字段），上传后核对一次即可。
  - 构建命令（自定义主控地址已确认内嵌为 `https://cnnic.link`）：
    ```powershell
    cd F:\mc\client
    $env:ELECTRON_MIRROR='https://npmmirror.com/mirrors/electron/'
    $env:ELECTRON_BUILDER_BINARIES_MIRROR='https://npmmirror.com/mirrors/electron-builder-binaries/'
    $env:VITE_MCLINK_MASTER='https://cnnic.link'
    node scripts/dist.mjs --win nsis
    ```
    （打包前先把正在运行的客户端关掉，否则会报 `remove d3dcompiler_47.dll: Access is denied`。）
- **升级后的界面变化**：房间页「连接路径」比 1.0.5 多一列「丢包」，右栏房间卡动作区多一颗
  「强制走中继」（整行）；设置页多一个「联机质量」分区。截图可参考
  `.impeccable/review/relay-1-room-loss.png`、`relay-5-settings.png`。
- 旧的安装包可以留在 `data/downloads/`（已装的用户会照常收到新版本提示），
  但不要再往群里发旧版本的链接。
