# McLink 1.1.1

**这一版只做一件事：让客户端不再绑死在官方主控上。** 官方服务已于 2026-10-07 停止，
所以这版客户端的重点是"你自己说了算"——换成你的主控、加上你的节点，照样联机。

---

## 玩家侧：想继续用，有两条路

### 1）用别人的/自己搭的主控

登录页底部多了一行 **「连接的是哪台主控？」**（默认折叠，点开可以改）：

* 填你自己的实例地址即可：`https://mclink.example.com` 或 `http://192.168.1.10:8787`
  （不写协议会按 `http://` 处理；粘贴带路径的地址会被自动截成域名，避免拼错接口）；
* **切换主控会退出当前登录** —— 你的账号只存在于原来那台主控上，这是设计而不是 bug；
* 界面里也如实写了：**登录时账号密码会发给那台主控**，只填你信任的实例。

设置页里同样能改（「自建 / 社区节点」卡片），并且多一个 **中继节点** 输入框。

### 2）接上社区 / 自建的 EasyTier 节点

设置页 →「自建 / 社区节点」→「中继节点」，一行一个，支持三种写法：

```
tcp://public.easytier.cn:11010
udp://public.easytier.cn:11010
public.easytier.cn:11010        ← 不写协议，tcp 与 udp 各加一条
```

* 这些地址会在**进房时被追加**到平台下发的配置里（平台给的中继仍然保留，只是多几个出口）；
* 改完 **退出房间再进一次** 才生效（配置在启动内核那一刻生成）；
* 社区公共节点列表见 <https://info.qtet.cn/uptime/easytier> ——**第三方提供，与本项目无关联**，
  可用性与可信度请自行判断；
* 填错的地址会被跳过并标出来，**不会**因此让房间起不来。

## 主控侧（自建实例）

* 新增「注册模式」：`开放 / 仅邀请码 / 完全关闭`；邀请码在控制台生成，可设备注、可用次数、有效期；
* 新增「本实例对公众开放」开关：关掉后落地页换成"已停止对外服务"的姿态
  （仓库地址 + 自建指引 + 邀请码注册入口），不再招徕使用者；
* 落地页/下载页会如实说明"这个包需要连到你的主控"；
* 自建步骤见 [docs/private-deployment.md](../private-deployment.md)。

## 其它修复

* **中继选路不再退化成"数据库行序"**：以前"没有测速数据"或"各节点同分"时，
  换台目标与建房选路会按数据库返回顺序取第一个（实测把玩家推到了德国节点）。
  现在无测速数据时只用国内节点、换台目标与建房同一套规则（延迟优先，差 ≤10ms 优先大管子）。
* **节点到线提醒更快**：判定改成"EWMA **或最近一次原始采样**越线"，持续超线约 **1 分钟**就会提示
  （原来要等 5~6 分钟）；「房间中继过载阈值 = 0」不再连带关掉这条提示。
* **换台目标与建房一致**：房间建房时的测速会存下来，换台时喂给同一套排序规则。
* 客户端探测"一台都没测到"时会重试；建房前最多等 4 秒（原来 1.5 秒就被截断 → 发空提示）。
* 邮件公告支持 **HTML**（同时自动附纯文本兜底）；控制台撰写框修成多行。

---

## 已知限制

* 客户端**不会**自动发现社区节点，也不内置任何节点列表 —— 官方不再运营节点，
  填什么、信不信由你；
* 切换主控后需要重新登录（旧令牌对新主控无效）；
* 中继节点是"追加"而不是"替换"：平台下发的中继仍然会被尝试，只是多几个出口；
* 停止对外服务之后，官方下载页仍在（软件开源、包可下），但**登录官方实例需要邀请码**。
