# 公告邮件：河北阿里云节点上线

**用途**：控制台「群发公告」里粘贴（主题 + 正文）。尾部会由主控自动附上站点名、站点地址与
退订链接，所以正文里**不要**再写签名和退订说明。

**主题**

```
河北阿里云节点已上线，中继连接异常已修复
```

**正文**

```
大家好，

两件事：

1）新增「河北阿里云」中继节点，已开放调度。华北一带的玩家建房联机会就近接入，延迟更低。

2）近期（1.0.9 版本期间）部分玩家遇到"连不上中继、进房后不通"的问题，经排查是常山联通、
常山移动这两台中继节点的网络环境异常导致的。这两台节点已下线，不再参与房间调度，
相关问题不会再出现。

如果仍有连不上或进房后不通的情况，请更新到最新版客户端后重试；还是不通的话，
把房间号发我们看一下。

（收到这封邮件的都是注册过账号的玩家，如有打扰可在邮件底部一键退订。）
```

## 备注（不发给玩家）

* 「常山联通 / 常山移动」的真实原因：这两台节点的接入层改写了客户端源 IP
  （内核看到的对端是 `100.64.0.0/10`），导致它们既看不见真实地址、也无法参与打洞，
  在选路上又赢不过能看见真实地址的节点 —— 一旦有房间把承载交给它们就会整片不通。
  详见 `docs/troubleshooting.md` §6.6 与本次排障记录。
* 河北阿里云节点是 EIP 直连（源地址保持），因此能正常承载与协助打洞。
* 公告正文控制在 200 字以内：太长容易被服务商判成垃圾邮件。
