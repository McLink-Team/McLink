## 正文（纯文本，可直接粘贴）

```
尊敬的 McLink 用户：

您好。

McLink 客户端 1.0.7 已发布，同时中继节点做了一次调整。现将本次变更说明如下。

一、中继节点调整

1. 下架「湖北腾讯云 200Mbps」节点

该节点在跑满带宽上限之后，链路质量会明显恶化（延迟抖动、丢包变差），
继续留在选节点列表里只会让选中它的玩家体验更糟，因此已下架。

已经建好的房间不受影响：平台始终会额外下发一个兜底中继入口，
你所选的节点不可用时，房间不会因此断开。

2. 新增两个 200Mbps 节点：常山移动、常山联通

两个节点均已上线，在「创建房间 → 中继节点 → 手动选择」里可以看到。
浙江及周边地区的玩家可以优先选择它们。

二、延迟显示改用 Tcping（读数更准确）

上面这两个新节点出于安全考虑，屏蔽了 ICMP（也就是禁 Ping）。
而旧版客户端在创建房间前是发 ICMP Ping 来测各个节点的延迟的，
遇到禁 Ping 的节点就只能显示「—」，玩家没法判断该选哪个节点。

为此，客户端改为用 Tcping：直接对中继的连接端口做一次 TCP 握手来测延迟。
这正是你进房间时真正要走的路径。因此：

· 禁 Ping 的节点现在也能正常测出延迟；
· 数字比过去更可信 —— 以前会出现"延迟很好看、但那个端口根本连不上"的情况；
· 每个节点会连打 3 次取最快的一次，偶尔丢一两个包不会再让读数变成「—」；
· 如果某个节点仍显示「—」，说明从你的网络连不上这个节点的端口，
  而不是这个节点"卡"或者"不能用"。

三、修正一处丢包提示的误报

部分玩家在房间里（尤其是所有连接都走中继时）会看到「P2P 直连在丢包」的提示，
其实那条读数来自"你到中继服务器"的连接，并不是玩家之间的直连。
现在判定只看「你到房主」这一条链路；房主本人不会再看到这条提示。
每个节点自己的丢包读数照常显示，但不参与这个结论。

四、升级方式

直接下载安装包覆盖安装即可，登录状态与本地设置都会保留，无需先卸载旧版本：

https://cnnic.link/downloads/McLink-Setup-1.0.7-x64.exe

已安装旧版本的用户，客户端内也会出现新版本提示，可直接跳转下载页。

五、反馈渠道

使用过程中如遇到问题，请在官方 QQ 群（1028142284）中反馈，并附上以下信息，
以便我们准确定位：

· 客户端版本号（窗口左下角）
· Windows 版本
· 界面上的提示文字（截图即可），或「设置 → 日志」中的相关内容

感谢您的使用与支持。

McLink 团队
2026-09-27

────────────────────────────────────────────
McLink —— 基于 EasyTier 的局域网联机平台，支持《我的世界》等各类局域网联机游戏。
官网与下载：https://cnnic.link/download
```

## 发送建议

- **收件人**：全量。节点调整对所有人都有意义（湖北节点下架后别再选它），
  而"禁 Ping 节点测不出延迟"这件事只有装了 1.0.7 才会消失。
- **发送顺序**：先上传安装包 → 再部署主控（V20 迁移 **+ `/nodes` 下发端口**）→ 最后发公告。
  顺序反了会出现"邮件已经发出、链接 404"或"装上新版仍然整列显示「—」"。
  本机开发库实测过这一步：**只跑迁移、不放安装包时**，`/meta` 与下载页的地址会退回
  `data/downloads/` 里现存的旧产物（`resolveClientDownloadUrl()` 找不到设置里指定的文件名就改挑现存的，
  见 `server/src/api/public.ts`）。放上 1.0.7 的包之后才变成 `/downloads/McLink-Setup-1.0.7-x64.exe`。
  顺带一句：`/meta` 的这个字段是**扫描目录后算出来的**，刚拷完文件的那一两秒里可能还回报上一次的结果，
  核对时以 `/downloads` 为准（它每次按文件现算 sha256）。
- **安装包指纹**（**以本次构建产物为准**）：
  - 文件名 `McLink-Setup-1.0.7-x64.exe`
  - 大小 `91,964,698` 字节
  - sha256 `079af802033ccfd8a9726c017ef1a8ec518151b93bd0d149e8c16f52199fcf1e`
  - 主控页面上显示的校验值由它自己按文件计算（`/downloads` 的 sha256 字段），上传后核对一次即可。
  - 构建命令（自定义主控地址已确认内嵌为 `https://cnnic.link`）：
    ```powershell
    cd F:\mc\client
    $env:ELECTRON_MIRROR='https://npmmirror.com/mirrors/electron/'
    $env:ELECTRON_BUILDER_BINARIES_MIRROR='https://npmmirror.com/mirrors/electron-builder-binaries/'
    $env:VITE_MCLINK_MASTER='https://cnnic.link'
    node scripts/dist.mjs --win nsis
    ```
    （打包前先把正在运行的客户端关掉，否则会报 `remove d3dcompiler_47.dll: Access is denied`。）
- **升级后的界面变化**：建房页「中继节点 → 手动选择」那一列的延迟数字换成 TCP 握手测出来的
  （数值会与之前略有差异，属正常）；测不到的节点显示「—」并排在最后，**仍然可以选择**。
- 旧的安装包可以留在 `data/downloads/`（已装的用户会照常收到新版本提示），
  但不要再往群里发旧版本的链接。
