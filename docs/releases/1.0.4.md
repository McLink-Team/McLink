## 正文（纯文本，可直接粘贴）

```
你好，

McLink 1.0.4 已发布。这次最明显的变化是：关闭窗口的行为现在由你决定，不再"悄悄躲进托盘"。另外修掉了几个
看起来正常、其实不对的问题。

【关闭窗口不再一声不吭】
以前点右上角的 X，窗口直接就没了、也不提示 —— 很多人以为已经退出，实际上进程还在后台跑着、房间也没断。
现在点 X 会先问你一句：

  · 最小化到托盘：窗口收起来，房间和朋友的联机保持不断（托盘图标右键可退出）；
  · 彻底退出：关闭客户端并断开局域网连接，房间里的朋友会掉线。

勾上「记住我的选择」以后就不再询问；想改随时到「设置 → 关闭窗口时」切换，也可以设成每次都问。

【权限：以前点了没反应的那个按钮，现在真的会重启】
  · 没有以管理员身份运行时，启动后会说清楚为什么需要权限，并给出「以管理员身份重启」（还能打开安装目录）；
  · 修好了这个按钮在安装版里点了没反应的问题（命令行参数拼接错误，只在打包版出现）。

【稳定性】
  · 显卡驱动异常导致界面崩溃时，自动改用软件渲染重开，不再反复崩；
  · 与主控的连接偶尔断开时，改为带随机抖动的重连，避免所有客户端在同一秒一起挤回来。

【联机体验】
  · 房间改成"无人活跃才过期"：只要你或朋友还在用，房间就不会因为到点被回收；
  · 开房会优先落到带宽充裕的节点，节点带宽吃紧时会在管理端告警。

【管理端 / 主控】
  · 用户管理列表可以直接看到邮箱；
  · 邮件公告支持按角色、活跃度或手填名单筛选收件人；
  · 节点新增「复制安装指令」「复制更新指令」，新节点接入和旧节点升级都是一条命令；
  · 新增"外来网络"全网聚合统计。

【怎么升级】
直接下载安装包覆盖安装即可，登录状态、房间设置都会保留，不需要先卸载旧版本：
https://cnnic.link/downloads/McLink-Setup-1.0.4-x64.exe

用下来有任何问题，欢迎在群里直接反馈（附上界面上的提示文字或日志更好定位）。

—— McLink 团队
2026-09-25

McLink —— 支持《我的世界》等各类局域网联机游戏的一键开黑工具。
```
