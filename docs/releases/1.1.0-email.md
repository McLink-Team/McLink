> 用途：控制台 →（群发邮件）「主题」+「正文」，**纯文本**。
> 平台会在正文尾部**自动追加**来源与退订链接（`——` / 站点名 / 站点地址 / 不想再收到公告邮件：…），

> 限制：主题 ≤ 80 字、正文 ≤ 4000 字；收件人是"已验证邮箱且未退订"的用户。
>
> ⚠️ 本版（2026-10-03 更新）覆盖的是**现在下载页上那几个 1.1.0 包 + 最新主控**的实际行为：

## 主题

```text
McLink 1.1.0 更新：房间中继只连一台，卡了能一键换到更近的节点
```

## 正文

```text
你好，

这次修的是一个很实际的毛病：房间里明明有中继，却怎么都连不通，或者总有一两个人进不来。
排查下来不是网络问题，而是"该由哪台中继转发"以前交给了 EasyTier 内核自己选，它会选错——
选中的那台恰好不转发数据，于是整片房间的数据被丢掉。现在改成由平台直接指定。

【这次改了什么】

1. 一个房间只连一台中继。房主和所有成员的票据里都是同一台，房间里再没有第二条会被误选的路。

2. 选哪台看"离你多近"。平台用建房那台电脑实测到的延迟挑最近的节点；如果两台差不到 10 毫秒，
   优先用带宽大的那台。以前还有一道"10M 带宽门槛"，会把 2M / 5M 的近节点整个筛掉，
   房间常常落到离你最远的 200M 节点上——已经删掉了。完全没有测速数据时，平台只会先在国内节点里挑，
   不会再出现"房间被安排到海外节点"这种情况。

3. 中继忙到上限会提醒你换。节点用到自己容量的 80%（小管子）/ 90%（其余）约 1 分钟，
   房间里就会出现提示，新版客户端还会响一声"叮咚"：房主点「立即切换」把房间整体搬到更空闲的节点
   （会卡顿几秒），其他成员点「重连」跟上。换台用的还是"就近优先、差 10 毫秒内优先大管子"
   这套规则，所以不会把你送到地球另一边。

4. 如果房间里所有人都是 P2P 直连（打洞成功、数据不经过中继），平台不会发任何提示，不打扰。

5. 中继节点忙到自己的线之后，不再接新房间；已经在里面的人不受影响。

【你需要做什么】

· 建议更新到 1.1.0：官网下载页 https://cnnic.link/download
  - Windows：McLink-Setup-1.1.0-x64.exe
  - 安卓：mclink-android-1.1.0-debug.apk
  - macOS：McLink-1.1.0-macos-arm64.dmg（Apple 芯片）或 McLink-1.1.0-macos-x64.dmg（Intel 芯片）
  安装包的 SHA-256 校验值在下载页上都能看到。

· 不更新也能继续联机，只是有三处差别：房间页的中继标注显示得不准、听不到"叮咚"提示音、
  房主切换中继之后不会提示你重连（只能自己退出重进）。所以还是建议更新。

· 更新之后如果正待在房间里：退出重进一次，就会用上新的中继规则（房主重进一次最有效）。

· 如果建房页里某一台节点的延迟一直显示"—"，说明本机没连上它的端口，点一下「重新测速」即可；
   这不会挡住建房，只是平台会少一份"距离"依据。

【已知限制】

· 一台中继到上限时只能整房搬走，所以要房主点一下确认——不会在你打 BOSS 的时候自动切。
· 你和别的成员之间能不能直连（P2P）取决于双方网络（对称 NAT 下多半打不通）；平台保证的是
  "每个人到房主一定通"——走房间里那台唯一的中继。房主也可以在房间里关掉「允许 P2P」，
  让所有流量都走中继（更可控，但更耗那台中继的带宽）。

感谢反馈这些问题的朋友。遇到其它毛病，欢迎在群里说，或者在客户端「设置 → 反馈」里告诉我们。
```

## 附：发信前的检查清单

1. **收件人**：控制台群发页先看「可发送」人数（已退订/未验证/被封禁/没填邮箱的都不会收到，属正常）。
2. **预览**：群发页的预览会显示最终正文（含自动追加的退订尾巴），确认排版没问题再发。
3. **节流**：平台按每批 5 封、批间隔 1.2 秒发送；人多了会跑一会儿，中途可以停。
4. **校验值**（如果要写进信里）：下载页会自动列出每个产物的 SHA-256，不用手贴；1.1.0 当前这几个是：
   - `McLink-Setup-1.1.0-x64.exe` → `3c850dd27c317852367207bd722d0f113ee701ff12460a0d89d3a2e9856295bc`
   - `mclink-android-1.1.0-debug.apk` → `ec732fb6476bb3c812a9f3bfad6e58185646859c8b49d39553d1f24905839006`
